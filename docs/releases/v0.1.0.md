# v0.1.0 — macOS 上的第一个公开发布

这是 discprobe 的 macOS 版本：让光驱**自己**测出一张已刻录光盘的螺旋几何（每个扇区在盘面上的
转角 θ(N)），得到内半径 r0 与轨距 p，并导出 DiscImageStudio 预设。不用扫描仪，不用拍照描点。

这一版在真机上跑通了完整链路（22 级梯子，χ²/dof 0.89），并把数值部分从 numpy 改写成了纯标准库：
**除 Python 3 和 Xcode 命令行工具外，没有任何第三方依赖。**

## 下载哪个

| 资产 | 用途 |
|---|---|
| `discprobe-macos-0.1.0.tar.gz` | 完整体验包：Python 代码 + 预编译的通用二进制（arm64 + x86_64）+ 本机实测数据。解压即可跑，不需要编译。 |
| `discprobe-spt-darwin-universal` | 只要传输层 helper 的人用（IOKit SCSITaskLib，可单独拿去做裸 CDB）。 |
| `SHA256SUMS.txt` | 上面两个文件的校验和。 |

```bash
tar -xzf discprobe-macos-0.1.0.tar.gz
cd discprobe-macos-0.1.0
python3 -m discprobe list          # disk10  MATSHITA BD-MLT UJ260AF 1.01
python3 -m discprobe selftest      # 不接硬件，模拟驱动器上跑完整流程
```

从源码跑也是同样三条命令；`tools/mac/build/discprobe-spt` 不存在时会自动执行
`tools/mac/build.sh` 编译（需要 `xcode-select --install`）。不需要 root，也不要加 `sudo`。

## 怎么测一张盘

```bash
python3 -m discprobe timing --drive disk10 --sectors 16 --reps 24   # 约 2 分钟：确认 FUA 与 CAV
python3 -m discprobe geo    --drive disk10 --max-targets 22 --reps 24  # 约 4 分钟：测几何
python3 -m discprobe disexport --geo results/geo-disk10-<时间戳>/summary.json \
    --sectors 2297888 --r-min 25.8 --r-max 54.5 \
    --output results/geo-disk10-<时间戳>/dis_preset.json
```

测量期间这张盘不能挂载，同一台驱动器同时只能有一个 discprobe 进程。

## 本机实测（MATSHITA BD-MLT UJ260AF，USB）

盘：DVD-R，MID `RITEKF1`，2,297,888 扇区，写满随机数据并已封盘。

| 量 | 值 |
|---|---|
| 缓存 / 读取策略 | plain 1016 µs、FUA 50665 µs → `fua` |
| 主轴 | 25.3826 ms 一圈（2363.8 rpm），三区一致 → CAV |
| 相位噪声 | 单次 0.72–1.10°，均值标准误 0.15–0.23° |
| 梯子 | 22 / 22 级，残差 rms 0.206°，χ²/dof 0.89，c = 0.011° |
| u = r0/b、v = p/b | 180518.475 ± 0.015、5.5912078 ± 0.0000006 |
| 内半径 r0 | **24.06311 mm**（标称 24.0） |
| 轨距 p | **0.745308 µm**（标称 0.74） |
| 角度不确定度 | 25.756–54.486 mm 内 0.146°；24–58 mm 内 **0.174°（1σ）** |
| 与标称几何的偏差 | 24–58 mm 累计转角差 **52218°**（约 145 圈） |
| DIS 预设 | 内 24.0631 mm / 外 58.2273 mm，与实测角度图最大差 0.0010° |

原始数据（两次不同参考扇区 + 一次纯标准库重建）在 `evidence/mac/`。

## 精度怎么用

报告的不确定度**偏乐观约 15%**：换参考扇区重测一遍，两次结果在 25.8–54.5 mm 内相差 0.279°，
而单次报告的 √2σ 是 0.246°。判断精度时按 **0.2° 量级**用。

## 已知边界

- 只测已刻录区，空白盘读不出数据；需要 CAV，低速档可能是 CLV（程序会警告）。
- 校准是逐盘的：结果对应"这批空白盘 × 这台刻录机 × 这个写速档"，换任一项都要重测。
- CD 的块长和轨道间距不同，参数要改；蓝光未验证。
- macOS 后端只在这个型号的 USB 驱动器上验证过。
