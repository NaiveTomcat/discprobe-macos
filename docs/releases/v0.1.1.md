# v0.1.1 — 预编译 helper 现在开箱可跑（签名 + 公证 + 自动清掉下载标记）

v0.1.0 的包里已经带了预编译的 `discprobe-spt`，但**从浏览器下载**的副本会被 Gatekeeper 拦下
（"Apple could not verify …" 然后被杀掉）。这一版把这条路打通了：

- helper 用 **Developer ID Application** 证书签名（hardened runtime + 时间戳），并提交 Apple
  公证服务，状态 **Accepted**；
- 裸命令行二进制**不能** staple 公证票据，所以签名公证本身仍挡不住 Gatekeeper。程序现在会检测
  `com.apple.quarantine` 标记并自动清掉（不需要 root），清不掉时（目录只读）就把字节复制一份到
  `~/Library/Caches/discprobe/` 再执行；两种情况都在 stderr 说明一行，不改动文件内容。

结果：**用户只需要 Python 3.10+**，不需要 Xcode 命令行工具、不需要 root、不需要手动 `xattr`。

## 下载哪个

| 资产 | 用途 |
|---|---|
| `discprobe-macos-0.1.1.tar.gz` | 完整体验包：纯标准库 Python 代码 + 已签名公证的 arm64+x86_64 helper + 实测数据 |
| `discprobe-spt-darwin-universal` | 只要传输层 helper 的人用（IOKit SCSITaskLib） |
| `SHA256SUMS.txt` | 校验和 |

```bash
tar -xzf discprobe-macos-0.1.1.tar.gz
cd discprobe-macos-0.1.1
python3 -m discprobe list        # disk10  MATSHITA BD-MLT UJ260AF 1.01
python3 -m discprobe selftest    # 不接硬件，模拟驱动器上跑完整流程
```

从源码 clone 也一样用；那种方式下 helper 会在首次运行时用 clang 编译（需要 Xcode 命令行工具）。

## 不需要 root

整条链路在普通用户下跑通：独占光驱用 IOKit 的 `ObtainExclusiveAccess`（盘未挂载即可成功），
清下载标记是对自己拥有的文件调用 `xattr -d`，退路是写 `~/Library/Caches`。本版所有实测都是 uid 501。

## 与 v0.1.0 的差别

- helper 签名 + 公证；macOS 拦截时的自动处理与提示；
- 文档补充：签名的边界（为什么裸二进制仍会被拦）、手动等价命令、没有编译器时的提示；
- 数值代码没有改动，实验数据不变：22/22 级，u = 180518.475、v = 5.5912078，
  r0 24.06311 mm、轨距 0.745308 µm，24–58 mm 内 0.174°（1σ）。
